# 伤情解剖模型可视化设计说明

## 1. 目标与范围

训练工作台中点击 GIS 伤员模型后，弹出伤情解剖详情窗口。窗口以人体解剖 GLB 展示当前伤员的引擎伤情，并突出显示受伤内部结构与出血状态。

本功能包含：

- 使用 `simulation/public/model/ztrw0818.glb` 作为详情窗口的固定解剖模型。
- 从训练会话快照的 `casualties[].injuries[]` 读取伤情部位和状态。
- 隐藏解剖模型的外层制服网格，展示内部组织。
- 高亮伤情对应的骨骼、肌肉、器官或血管节点。
- 对未控制的出血伤情显示脉冲红色伤口标记。

本功能不包含：

- 修改 C++ 引擎伤情演化逻辑。
- 新增 Java 查询接口或由前端推导权威伤情。
- 在没有左右侧数据时猜测左侧或右侧肢体。

## 2. 数据契约

伤情数据来自 Java 返回的训练快照，Java 透传 C++ 引擎事实数据。前端使用字段如下：

| 字段 | 来源 | 用途 |
|---|---|---|
| `injuryId` | `injuries[]` | 伤口效果的稳定标识 |
| `region` | `injuries[]` | 解剖区域匹配 |
| `organ` | `injuries[]` | 目标结构匹配 |
| `severity` | `injuries[]` | 高亮和伤口脉冲强度 |
| `bleedingRate` | `injuries[]` | 出血效果强度 |
| `controlled` | `injuries[]` | 控制后停止红色脉冲 |

当前快照已包含 `region` 和 `organ`，前端不再请求额外的受伤部位接口。若后续需要显示左侧或右侧上肢，C++ 引擎应在每条伤情中增加 `side`，取值为 `left`、`right`、`bilateral` 或 `unknown`；Java 保持透传。

## 3. 模型与节点策略

详情模型固定地址为：

```text
/model/ztrw0818.glb
```

该模型包含独立的 `解放军` 外层网格，以及中文命名的内部节点，例如 `肺部`、`胸腔骨骼`、`血管`、`左上肢骨骼` 和 `右上肢骨骼`。

点击详情时：

1. 仅隐藏 `解放军` 外层制服网格，不移除模型文件中的节点。
2. 通过前端静态映射将 `region + organ` 映射为内部目标节点。
3. 未命中具体器官时，回退到区域节点，保证伤情仍有可见反馈。
4. 当前引擎未传递左右侧信息时，上肢伤默认同时显示左右上肢对应结构，不伪造侧别。

初始映射如下：

| `region` | `organ` | 内部目标节点 |
|---|---|---|
| `chest` | `肺` | `肺部` |
| `chest` | `肋骨` | `胸腔骨骼` |
| `chest` | `主动脉` | `血管` |
| `upper_limb` | `肱骨` | `左上肢骨骼`、`右上肢骨骼` |
| `chest` | 其他 | `胸部肌肉`、`胸腔骨骼` |
| `upper_limb` | 其他 | `左上肢肌肉`、`右上肢肌肉` |
| `abdomen` | 其他 | `腹部肌肉` |

映射集中维护在 `simulation/src/config/injuryVisualMap.js`，新增伤情类型时优先扩展该文件。

## 4. 呈现规则

### 4.1 外层剥离

当伤员至少存在一条引擎伤情时，查看器隐藏 `解放军` 外层制服网格，使内部解剖节点可以直接观察。当前模型的制服是单一外层网格，无法只移除局部衣物，因此采用整体剥离。

### 4.2 内部结构高亮

- 未控制伤情：目标节点使用红色发光材质并周期性脉冲。
- 已控制伤情：目标节点使用黄色标记，不再脉冲。
- 多条伤情：目标节点取并集；同一节点同时存在未控制和已控制伤情时，未控制状态优先。

### 4.3 伤口与流血效果

查看器以目标节点包围盒中心作为伤口标记位置：

- 未控制伤情：红色球形核心、扩张环和点状粒子共同脉冲。
- 强度：由 `severity` 与 `bleedingRate` 共同决定，较重且出血量更大的伤情更明显。
- 已控制伤情：取消红色脉冲和粒子，仅保留黄色稳定标记。

效果仅为训练可视化提示，不表示精确解剖穿透路径。

## 5. 前端模块边界

| 模块 | 职责 |
|---|---|
| `SimulationConsole.vue` | 打开详情窗口，向查看器传递当前伤员的原始 `injuries[]`。 |
| `injuryVisualMap.js` | 维护引擎伤情字段到解剖模型节点的静态映射。 |
| `injuryModel.js` | 归一化伤情可视化数据，提供映射、回退和强度计算。 |
| `CasualtyModelViewer.vue` | 加载 GLB、隐藏外层、更新内部材质、创建和播放伤口效果。 |

## 6. 验收标准

1. 点击 GIS 中的伤员模型后，详情窗口加载 `/model/ztrw0818.glb`。
2. 存在伤情时，“解放军”外层制服网格不可见，内部结构可见。
3. 肺、肋骨、主动脉和肱骨伤情能映射到对应内部节点。
4. `controlled: false` 的伤情显示红色脉冲伤口和高亮。
5. `controlled: true` 的伤情停止红色脉冲，改为黄色稳定标记。
6. 多伤情同时存在时，各目标节点和标记可同时显示。
7. 未匹配到具体器官时，至少显示该区域的回退高亮，不抛出页面错误。
8. 前端单元测试覆盖具体匹配、区域回退、受控状态和视觉强度计算；`npm test` 与 `npm run build` 通过。
